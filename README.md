# Food Delivery App (Zomato-Style Role Demo)

This is a lightweight front-end demo of a food delivery app with three role-based panels:

- Customer App
- Restaurant App
- Delivery Boy App

## Features

- Customer selects restaurant and food item, then places order.
- Restaurant accepts order and marks it ready.
- Delivery boy picks up and delivers order.
- Shared order timeline updates step-by-step.

## Run locally

Open `index.html` in your browser.
